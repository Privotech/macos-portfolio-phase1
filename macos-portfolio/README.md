# 🖥️ Privotech — Portfolio OS

A fully interactive macOS-inspired portfolio web application.

## Tech Stack

- ⚡ React + Vite
- 🎨 Tailwind CSS
- 🎞️ Framer Motion
- 🐻 Zustand
- 🖱️ React Draggable
- 🎯 React Icons

## Getting Started

```bash
npm install
npm run dev
```
